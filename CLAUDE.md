# CLAUDE.md

This repository is used for ongoing UI/UX prototyping. The prototype is a single
self-contained page, `index.html`.

## Workflow

- Work directly on the `main` branch whenever the environment permits it.
- After each approved design change, create a descriptive commit and push directly to `main`.
- Do not create pull requests unless explicitly requested.
- GitHub Pages publishes from `main`, so every push to `main` goes live.
- Never publish unrequested design changes.

## Git history

- Preserve the complete Git history.
- Never force-push, rebase, amend, or rewrite existing commits.
- Use `git revert` when asked to undo a previous change.

## Code

- Keep `index.html` functional and preserve unrelated design elements.
